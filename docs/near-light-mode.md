# 近光速実験モード

2026-11-04更新。無料のクライアント描画のみ。通常の0–2000 km/hの空気抵抗・衝突ソルバーとは分離する。

## 計算するもの

地上基準の初速を0.9c、0.99c、0.999cから選ぶ。c = 299792458 m/s。野菜の質量は既存の代表値。
初期運動エネルギーK=(γ−1)mc²、運動量p=γmv、真空12mの等速飛行時間12/vを既存の安定化した相対論の式で計算する。
真空映像の移動はこの等速運動を3秒に引き延ばす。進行方向の寸法は1/γとした地上同時刻の模式図。光の到達遅れ・ドップラー効果・見かけの回転等を含む光学的な映像ではない。発射前は静止形状。加速機構は扱わない。
真空の比較に的は設置せず、12mで終了する。衝突・貫通は予測しない。

## 計算しないもの

大気中の巨視的な野菜の軌道、崩壊時刻と場所、温度、放出エネルギーの分配、粒子輸送、放射線量、衝撃波の圧力、建物損傷、被害半径。
大気の映像には物理的な時刻を割り当てない。野菜形状が消える位置・光る経路・広がり・色は、相互作用を示す定性的な仮説の演出であり、測定値や計算結果ではない。経路は12mの表示枠に収めたもので、実際に12m進めるという意味ではない。光る線は粒子シャワーの解ではなく、輝度や幅もエネルギーや線量に対応しない。
画面に表示するエネルギーは発射直後の運動エネルギーのみ。「この全量が街に放出された」という意味ではない。現実の建物被害は未計算。ゲーム用の破壊規則を追加したが、画面にも「破壊はゲーム用の仮定」「実際の被害予測ではありません」と表示する。
通常モードの破損閾値・弱い音波モデルを近光速まで外挿しない。100%cの入力は受け付けない。

## 根拠と限界

- [UNSW: Einsteinlight / relativistic energy](https://newt.phys.unsw.edu.au/einsteinlight/jw/module5_equations.htm): γとエネルギー、v→cの極限。式の根拠。
- [Lechner, CERN (2018): Particle interactions with matter](https://e-publishing.cern.ch/index.php/CYRSP/article/view/714): 荷電粒子・光子・ハドロンの相互作用とシャワー。大気中の野菜の実証モデルではない。相互作用の種類を調べるための資料であり、発光形状や街の被害を裏付けるものではない。

ブラウザーでは発射、停止、コマ送り、任意位置の再生、真空との比較ができる。アニメーションは決定的な表示時計で動くため、停止中に物理時間が進むことはない。タブが非表示の間は再生を止める。

## 破壊サンドボックス（ゲーム規則v2・街区拡張）

自由な比較遊びのため、エネルギーKの対数を0〜1に圧縮した強度 `P=clamp(log10(K/1e16)/2.65,0,1)` から、表示上の到達範囲 `32+78P` を設定する。原点は街の表示座標(0,1.6,-6)、ガラスには1.18倍の範囲を使う。これは**物理的な爆風の半径や建材強度の計算ではない**。近光速の実被害がこの街に収まるという意味でも、残った建物が安全という意味でもない。通常モードには適用しない。

表示時計で順に窓が割れ、薄い外壁・床板が崩れ、粉塵が薄れて瓦礫が残る。建物内部は空洞の外皮・床板として表す。板の配置、回転、静止位置は演出で、構造解析や破壊後の質量保存を主張しない。描画は3組のInstancedMeshを使う。9秒で完了。光を消して瓦礫を見渡せる視点へ移り、同じ視点のまま破壊前と比較できる。

点数は倒壊1棟100点・窓1枚10点・設備1個25点。金額・物理的損害・人的被害とは無関係。6種の野菜×3速度の結果を実験帳に記録する。同条件の再生では記録を置き換え、点数を累積しない。保存はこのブラウザーのlocalStorageのみで、外部への送信やログインはない。保存不可でもゲームは続行できる。

街は16棟から108棟へ拡張。並行道路6本、横道、公園4区画を追加し、追加建物にも通常モードの衝突判定と近光速モードの演出破壊を適用する。新しい建物の窓模様はプロシージャルな外壁テクスチャ。窓の点数は従来の51代表面を数え、外壁に描いた全ての窓を個別計算するものではない。遠景建物の瓦礫は最大3層の板で表現して描画負荷を抑える。公園の木も演出の進行に合わせて倒れる。

「街全体」で108棟の配置と破壊前後を俯瞰できる。得点上限が変わるため、実験帳はv2用の保存キーへ分離した。v1の保存データは削除せず保持する。

## 地球規模との比較

地球破壊のアニメーションを追加する根拠は、現在の設定にはない。最大の2kg・0.999cでは初期運動エネルギーは約3.8406×10¹⁸ J。
[NASA Earth Fact Sheet](https://nssdc.gsfc.nasa.gov/planetary/factsheet/earthfact.html)の質量5.9722×10²⁴kg、平均半径6371kmから、一様密度球の重力結合エネルギー3GM²/(5R)を計算すると約2.2419×10³² J。最大設定はこの約5.84×10¹³分の1（約58兆分の1）であり、このエネルギーで地球を分散させることはできない。現実の地球の内部構造が一様ではない点に注意。

参考として[LPIのチクシュルーブ衝突の推定値](https://www.lpi.usra.edu/science/kring/Chicxulub/discovery/)約1億メガトンTNT相当を、約4.184×10²³ Jとして比較する。エネルギーは推定幅を持ち、隕石と相対論的な物体の大気中の放出過程は同一ではない。この比較を環境被害のしきい値や被害面積に読み替えない。現在の最大値はこの参考値の約10.9万分の1。地球全体への環境影響は依然として未計算。

ゲーム内の「地球と比較」は選択中の野菜・速度に連動した対数グラフ。局所の大きな被害、全球の環境変化、惑星自体を分散させることを区別する。さらにcへ近づくと理論上Kは上限なく増えるが、質量のある野菜のv=cは定義可能な発射条件ではない。
