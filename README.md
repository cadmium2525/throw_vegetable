# やさい投擲実験所

Three.jsで街中に野菜を投げ、波の広がりと破片の行き先を観察する無料のブラウザーゲーム。

[ゲームを開く](https://cadmium2525.github.io/throw_vegetable/)

## 起動

Node.js 22.12以上を用意して実行します。

```sh
npm ci
npm run dev
```

表示されたURLを開きます。ゲージに合わせて「投げる」をタップ。設定から0〜2000 km/hを直接指定できます。スペースキーにも対応。

通常投擲は実時間で、野菜を近くから追うカメラです。「スローで見る」でのみ時間を引き延ばします。衝突時は野菜の果肉・飛沫と、12mm合板を仮定した的の穴・木片を推定表示します。

的に穴が開いた場合は、抜けた破片を着地まで追います。手前への飛沫や、的・地面に残る果肉も表示し、次の一投まで残します。通過する量と衝突後の速度は仮定値です。

「街を俯瞰」で全体表示、「波 ON/OFF」で伝播の模式図を切り替えます。スロー再生でも波と破片は同じ時間倍率です。「観測結果」で波の到達時刻、直撃面、窓の破損（仮定）を確認できます。

**現実の被害を検証済みの精度で再現するものではありません。** 空中崩壊は有効強度を仮定した平均軌道モデルです。先端の気体圧力・温度と、衝突音の圧力を条件付きで計算します。飛行中のソニックブームの遠方圧力・反射・回折・建物の倒壊は未計算です。

設定の「物性の仮定」で空中崩壊をON/OFF、有効強度50〜1000kPa、衝突音への変換率0.01〜1%を比較できます。標準値は全野菜共通150kPa・32片・0.1%で、実測値ではありません。崩壊時も質量・平均運動量を保ち、総投影面積の増大によって減速します。「観測結果」で形状維持の場合との衝突エネルギー比較ができます。

## GitHub Pages

1. このフォルダーの内容を公開リポジトリの `main` にpush。
2. リポジトリの **Settings → Pages → Source → GitHub Actions** を選択。
3. **Actions → Deploy to GitHub Pages** が成功すると公開されます。設定前の初回実行が失敗した場合は再実行してください。

`.github/workflows/pages.yml` を設定済み。相対パスなのでリポジトリ名によらず動きます。公開リポジトリと標準のGitHub Actionsランナーを利用すれば、GitHub Freeでホスティングできます。[GitHubの説明](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)

有料API・サーバー・画像素材は不要。野菜、背景、音はコードで生成しています。

## 物理の範囲

街は108棟・複数の並行道路と横道・公園へ拡張しました。「街全体」で俯瞰、「地球と比較」で選択した野菜のエネルギーと地球規模の参考値を比較できます。現在の最大設定は地球を分散させるエネルギーに大きく届かず、全球の環境影響も未計算のため、地球が砕ける演出は入れていません。

「近光速実験」では、光速の90%・99%・99.9%で発射できます。真空の等速移動と、大気中の破壊サンドボックスを切り替え、停止・コマ送り・再生位置の変更で観察できます。窓・建物・設備の破壊、残る瓦礫、破壊前との比較、18条件の実験帳があります。初期エネルギーと真空12mの飛行時間は相対論で計算。破壊範囲と点数はゲーム用の規則で、現実の街の被害予測ではありません。[近光速モードの計算範囲](docs/near-light-mode.md)。

重力、Mach依存の空気抵抗、連続衝突判定を計算。飛行中は形状維持または等径破片群の平均軌道の近似で、抵抗係数・崩壊強度は仮定値です。衝突後は法線方向の運動エネルギーによる演出用の分類を使います。**実物の破砕・変形・貫通を予測する実験シミュレーターではありません。**

式・仮定・出典は [docs/physics.md](docs/physics.md)。
